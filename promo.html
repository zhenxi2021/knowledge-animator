一个小工具的自白

让原理自己演给你看

我做了一个叫 knowledge-animator 的东西。它不神奇，不能替你想清楚原理；它只做一件事——把你想清楚的东西，变成一份能播放的动画课件。

你大概也有过这种时刻：盯着一篇讲 TCP 拥塞控制、或者 Tailscale 怎么组网的长文，段落一行行往下读，脑子里却怎么也拼不出那股"流动"。文字是静止的，可网络里的包是活的——它们一来一回、一拥一退，在 NAT 后面悄悄打个洞又缩回去。

我自己就常被这种"知道，但没看见"卡住。画过的架构图能铺满一整面墙，可图是死的：谁先动、谁后动、哪条线其实根本没通，全得靠读者自己在脑补里补帧。补不上的时候，原理就停在"我好像懂了"的门口。

后来我想，与其再写长一点，不如让它能动。下面这三个小动画，就是这份课件里真实会发生的样子——不是截图，是活的。

① 一个包，是怎么走完一段链路的

一次请求：从你设备出发，经过节点，到达对端。绿点就是那个在跑的包——它走过的路，就是文字里那句"转发"真正发生的过程。

这第一帧，解决的是"静止"的问题。但更让我舒服的，是下面这个——它把"理解"也拆成了一格一格。

② 每按一次 →，就揭开一帧

五个步骤，逐个亮起。你可以按空格让它自己一路演下去，也可以手动一帧帧推进——讲到哪、停在哪，节奏在你手里。复杂的东西，往往是被"一次全倒出来"吓退的；一格一格，反而轻。

做到这一步，其实已经够用了。但我总觉得还差一口气：能看，能不能摸？于是有了第三样东西——实验页。

③ 你亲手拖一下，看见"条件变了会怎样"

NAT 严格程度 2

当前：P2P 直连 · 延迟 ≈ 20ms · 端到端加密，不经第三方

把滑块往右拖过一半，直连打不通了，连线自己折向中继、颜色也变橙——这正是 Tailscale 在"打洞失败就走 DERP"时的真实行为。读者不是被告知，而是亲手试出来。

它不替你思考，但它把"想清楚的东西"演得清清楚楚。对我来说，这就够了——因为大多数时候，卡住的不是脑子，是画面。

整份课件是一个零依赖的 HTML 文件，约 60KB，双击就能在任何浏览器打开。暗色、亮色两套主题，目录、全屏、深链都齐了。更踏实的是，每一份在交付前都会过三道关：结构自检（引用的节点 ID 是不是真存在）、浏览器冒烟（真跑一遍会不会报错）、还有我盯着关键页截的图——布局有没有溢出、标签有没有挤在一起。

它已经自带两份成品当样例：一份讲 TCP 拥塞控制（慢启动、拥塞避免、还有那条会自己长的 cwnd 曲线），一份讲 Tailscale 怎么工作（NAT 打洞、DERP 兜底、零配置组网）。你看到的上面三个动画，就是它们里头的真实片段。

想自己做一个，大概是这样：
  1. 拿 assets/starter.deck.js 当底，改里面的 slides 数组；
  2. node scripts/check.mjs 你的deck.js —— 静态自检；
  3. node scripts/build.mjs 你的deck.js —— 生成单文件 HTML；
  4. node scripts/smoke.mjs 你的deck.js —— 真浏览器跑一遍；
  5. 打开 HTML，按空格，看它活过来。

如果你愿意，它也能一键装到 claude / codex / workbuddy / qoder / openclaw / opencode 这些环境里——./install.sh 会自己认出你装了哪些。但我最希望的，其实是你拿它去讲一个你心里惦记很久、却一直没讲顺的东西。

毕竟，能让一个人"啊，原来是这样"地笑一下，比任何漂亮的参数都值钱。
