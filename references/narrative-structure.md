# Narrative Structure · 怎么把原理拆成 12-27 页

> 一个常见错误是把"我知道的所有内容"按知识自身的逻辑铺开。结果：读者看了一半就跑了。
> 课件的结构应该跟着**读者建心智模型的顺序**走，不是跟着**学科章节**走。

## 心智模型建设四段

任何复杂原理的掌握都过这四关——你的课件结构应完全对齐：

| 阶段 | 读者在问什么 | 你该出现的内容 |
|---|---|---|
| 1. 痛点 | 为什么要关心？ | cover、map、第一个 scene（"没这个东西会怎样"） |
| 2. 形状 | 它长什么样 / 怎么分 | 对比表、关键概念图 |
| 3. 行为 | 它怎么动 | 多个 scene，按"由静到动"或"由粗到细"排列 |
| 4. 落地 | 真实现里是什么样的 | code 页、lab 页、index 页 |

## 12-27 页的分配（推荐起点）

| 阶段 | 页数 | 页型 |
|---|---|---|
| 痛点 | 1 cover + 1 map + 1-2 scene | 4 页 |
| 形状 | 1-2 scene + 1 compare | 3-4 页 |
| 行为 | 3-5 scene | 5-7 页 |
| 落地 | 1 code + 1 lab + 1 index + 1 end | 4 页 |

> 12 页是"能讲清一件事"的最小集合；27 页是"能讲清楚一件事的所有有趣角落"。中间自由增减。

## 单页节奏控制

- **每页一个核心观点**，别把多个论点塞进一张图
- **每页 3-7 个步骤**（scene/compare/code）：
  - < 3 = 信息密度太低，不值得翻页
  - > 7 = 步进疲劳，读者记不住
- 每步 `dur` 控制在 **1.2-2.4 秒**（短信息 1.2-1.5，长概念 2.0-2.4）。默认 2.0
- 每步 `note` **1-2 句话**。逼自己写短——如果超过 80 字，拆成两步

## 一个具体的拆解流程（推荐照做）

### 第 1 步：列要点
在一张白纸（或任何文本框）里**快速**列 8-15 个「想讲清的点」，不要排序：

```
- 拥塞是个黑盒
- ACK 自时钟
- cwnd vs rwnd
- 慢启动指数
- 拥塞避免线性
- 状态机
- 重复ACK = 砍半
- 超时 = 归零
- AIMD 公平性
- Reno / Tahoe / CUBIC
- Linux 核心代码
- 互动实验
- RFC 5681 / 9438
- Jacobson 1988
```

### 第 2 步：四桶分堆
把上面那些点扔进四个桶：
- **痛点**：① → 1 桶
- **形状**：③, ④, ⑤, ⑥, ⑦, ⑧, ⑨ → 2 桶（先有静态画面）
- **行为**：②, ⑩ → 3 桶（动画把这几件事"演"出来）
- **落地**：⑪, ⑫, ⑬, ⑭ → 4 桶

### 第 3 步：分配页型
- 1 桶 → cover + map + scene 1（黑盒）
- 2 桶 → scene 2-3（窗口、慢启动）+ compare（Reno/Tahoe/CUBIC）
- 3 桶 → scene 4-5（状态机、AIMD）
- 4 桶 → code + lab + index + end

### 第 4 步：定每页的核心句
为每页写一句「读者翻完这一页应该记住的话」。例：
- scene 1 (黑盒)："发送方看不见网络，只能通过丢包反推"
- scene 4 (状态机)："重复 ACK 砍一半，超时归零重来"
- lab："调 ssthresh 和丢包时机，看 cwnd 锯齿怎么长出来"

如果一句说不清，就拆成两页。

### 第 5 步：自检三连问
- 翻完一遍，**5 分钟不回头**，能背出每页的核心句吗？不能——那哪页没起作用？
- 每一页的 `note` 是不是**自解释**的？（跳着看的人也该懂）
- 如果删去一整页，**故事会不会塌**？不会——那它是冗余的，删掉

## 反模式

| 反模式 | 表现 | 解决 |
|---|---|---|
| 大段文字背景 | 读者直接跳过 | 一页一图，三句话以上就拆 |
| 先讲历史 | "1970 年 Van Jacobson..." 读者会跑 | 从痛点切；历史放 `index` |
| 概念定义一上来 | 概念在没上下文时就是噪音 | 让概念先**出现一次**（黑盒页出现了"cwnd"），后面再展开 |
| 没有 lab | 读者只看动画，没有自己拨一下的记忆深刻 | **至少 1 个 lab**，给一两个可调参数 |
| 用 emoji / 太多颜色 | 把"工程课件"做成营销页 | 主色 `--acc` 1-2 个，强调用 warn/bad 即可 |
| 动画 30 个 step 一气呵成 | 读者根本来不及看 | 每 scene 控制在 5-8 step；多就分页 |
